# 햇살 새 버전 보관함

정현 · 찬양이 함께 쓰는 프로그램 **햇살**의 설치 파일을 두는 곳이에요.

- 햇살(0.9.0 이상) 왼쪽 위 **업데이트** 버튼이 [`latest.json`](latest.json)을 보고 새 버전을 받아요. 윈도우 · 맥 모두.
- 설치 파일은 `files/<버전>/` 에 45MB 조각으로 나눠 두었어요. (GitHub 파일 한 개 100MB 제한 때문)
- 처음 설치할 때는 [`install/`](install) 폴더의 파일 하나만 받아서 실행하면 돼요.
  - 윈도우: `햇살 설치 (윈도우).cmd` → 더블클릭
  - 맥(애플 칩): `햇살 설치 (맥).applescript` → 더블클릭 → 스크립트 편집기의 ▶
- 설치 파일만 있어요. 햇살은 로그인해야 쓸 수 있고, 우리집 데이터는 여기에 없어요.
